## What changed

Buffer synchronization uses horizontal accelerator copies, with a maximum
256-byte block and a shared PORT_Y for both buffers. Changed regions merge
without forcing a full-screen copy on ring overflow. A complete board logs
one rectangle, draws eight wide checker bands and then its occupied cells.
Individual cells and flashes use additional precomposed 48×24 rasters.

Eight additional pages allocate **exactly 128 KiB**, including code,
location tables, precoloured glyphs and a four-entry string cache. Stack and
network buffer addresses stay fixed. Precolour and string caching remain
**off by default**: the measured miss/precolour costs do not justify a
normal-gameplay switch.

Overlay computation admits interrupts; window changes still use DI.
Text pre-scanning yields every eight characters, and dirty-region merging
runs after restoring system WIN0. See the [render contract](../sprinter-render-contract.md).

## Measured MAME results

Turbo 21 MHz, actual release code, 30 samples per scenario. Times are
medians; the [performance report](../sprinter-render-budget.md) includes
maxima, first output, eviction, bytes and hardware operations.

| Operation | Archived 40×20 | Current |
| --- | ---: | ---: |
| Occupied cell draw | 1.466 ms | 0.991 ms |
| Initial board draw, 32 pieces | 71.131 ms | 42.642 ms |
| Initial board frame wait | 10.805 ms | 18.811 ms |
| Initial board synchronization | 195.177 ms | 18.638 ms |
| Initial board full cycle | 277.114 ms | 80.091 ms |
| Five-character line draw | 0.723 ms | 0.863 ms |
| 38-character line draw | 4.524 ms | 5.153 ms |

The **20 ms board target is missed by 22.642 ms**. The normal long-line
**1 ms target is missed by 4.153 ms**. Optional cache first output is
8.252 ms, repetition 1.257 ms and eviction 8.525 ms. Neither a hit-only
claim nor the historical 13.9 ms empty-grid measurement counts as a pass.
Isolated tile, cursor, selection and text drawing regressions remain
visible in the full report; the improvement is principally board painting
and buffer synchronization.

## Code review follow-up (2026-10-30)

Fixed unsigned width underflow in the fast string-cache path: X beyond
640 pixels now rejects the hit and leaves both VRAM buffers unchanged.
Precoloured glyphs now fall back to the original compositor for a changed
font page or nonzero font generation. MAME regression checks cover X=642
with a primed cache and an actually modified glyph raster.

Asset generation has one Make owner for the complete output group, so
parallel builds cannot truncate each other's page/include files. The
ensure pass tracks input hashes, preserves valid output timestamps and
repairs missing outputs. A parallel eight-target build and a missing-file
regression test pass. An unreachable jump was removed, recovering two
WIN2 bytes without changing rendering.
