# S14 — piece sets and palettes

Use `build/sprinter/SHATRANJ-SMOKE.IMG` in MAME or extract
`build/sprinter/SHATRANJ-HW.zip` into one directory on hardware.
The ZIP contains the EXE and all three network DLLs.

The menu order is FILE, DISCC, RESET, FLIP, THEME, PIECES, ABOUT.
PIECES cycles California → MPChess → Totoy → California. A fresh launch
starts with California. Arrow navigation wraps through all seven tabs;
Enter and Space activate the focused tab. The last two tabs must appear
at the right side of the menu without wrapping to the left.

## Acceptance checklist

- Cycle all three sets in each of the five board themes. Check all twelve
  pieces on light and dark squares and during the move flash.
- Select a piece with legal-move hints visible, then change PIECES. The
  selection, hints and cursor must return at their previous model squares.
- Repeat while the board is flipped. Change THEME and confirm the piece
  shape and colours remain selected.
- Open and dismiss About, including the fades. The chosen set and theme
  must return. Check save/load, reset, disconnect and a new network game;
  these must retain the selected set until application exit.
- Restart the application and confirm California is selected again.

## Automated coverage

The packer checks set names and order against the palette and derives the
normal/flash location table from its packing results. Pixel round trips
cover all 108 committed tiles. The host menu test covers both six-tab
ZX/Next and seven-tab Sprinter navigation and Enter/Space actions.
The shipping Z80 menu overlay is tested for 300 switches, palette data,
theme isolation, staged labels and X coordinates above 255. Distinct
synthetic set colours check that only entries 4–7 are replaced, and a
call through the real `video_init` verifies the selected colours survive. A separate
shipping-code test covers all 108 renderer slot/page combinations.
Existing fade, About restore and WIN3 dispatch tests remain in the gate.
