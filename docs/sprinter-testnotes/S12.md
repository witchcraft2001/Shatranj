# S12 — 40×20 pieces

Use `build/sprinter/SHATRANJ-SMOKE.IMG` for MAME. For real hardware, extract
`build/sprinter/SHATRANJ-HW.zip` into one directory: SHATRANJ.EXE,
UNETESP.DLL, UNETRTL.DLL and UNET509B.DLL must remain together.

EXE SHA-256 (release file and both packages):
`2a34d6b0fe2c1d4696e7f79282015ec14011ea8f12f72aebe96ec2debdb02e58`.

## Expected appearance and behaviour

Pieces now use 40×20 PNGs, centred at (+4 pixels,+2 rows) in the same
48×24 cells. The palette, five themes, cursor/selection frames, hint
markers and menu order are unchanged. PIECES cycles California → MPChess
→ Totoy → California; a fresh launch selects California.

Inspect all twelve pieces in each set on light/dark squares and yellow
move flash. Check king crosses, crown beads, rook teeth, bishop cuts and
knight profiles. MPChess black king, queen, bishop and knight keep their
separate bases; its black rook keeps all three separate components.
California's gray highlights remain darker than its added outside rim.
White figures have their source contour without an added light rim.

Select a pawn with movement hints enabled, cycle PIECES and THEME, and
FLIP the board. Selection, hints and cursor must remain attached to their
model squares. Open/dismiss About and check the same set, theme and
markers after both fades. Repeat after save/load, reset, disconnect and a
new network session. These actions must retain the selected set until exit.

## Automated results

- `make sprinter-check`: passed, including deterministic image/ZIP rebuilds.
- `make full-check`: passed. Existing release TAP/DAT/OVL and NEX, and the
  committed Next sprite/About assets, retain their pre-change SHA-256.
- Packer v2: all 108 light/dark/flash variants round-trip to PNG pixels;
  every 400-byte tile has 112 zero pad bytes. Four pages use HDR indices
  1, 2, 10, 11, with no group crossing a page. Set order and transitions
  inside each set are checked.
- Shipping Z80: all 108 addresses, 300 set switches, palette isolation,
  real `video_init`, missing-page guards, 20×20-byte blit parameters,
  FLIP, flash offsets and absent-page suppression pass. Existing About,
  fade, hint, WIN3 and calling-convention tests pass.
- Conversion regressions cover diagonals, arcs, bridges, open cuts,
  separate components and the reviewed topology of all 36 real figures.
  A complete browser import reproduces the installed PNG bytes.
- WIN1: 15987/16000 bytes (13 free). Cold page: 16359/16384 (25 free).
  WIN2 passes the layout/section guards. The 25-byte piece state takes
  20 bytes from spare space; network buffers and stack anchors stay fixed.

## MAME results

Scripted MAME visual review passed for all three sets and five themes,
selection/hints during a set change, FLIP, About/fade restoration, and a
legal hot-seat e2e4 with yellow flash. Pixel verification covers 544 piece
rectangles (435200 pixels) and six exact flash captures. Screenshots and
raw timing logs are under `build/sprinter/pieces40-mame/`; the machine-
readable result is `report.json` in that directory.

Compared with the archived production 32×16 build, tile drawing rose
23.34%, occupied-cell drawing 6.47%, full initial-board drawing 4.18%, and
set change plus repaint 3.98%. Full paths include real `frame_wait` and
buffer synchronization. See [render budget](../sprinter-render-budget.md)
for medians and limits; the old 13.9 ms stand result is not this baseline.

SVG → 32×16 → 40×20 colour/silhouette comparisons:
`build/sprinter/preview/pieces40/{california,mpchess,totoy}-comparison.png`.
The same directory contains actual-scale and nearest-neighbour 4× previews
for both square colours in every theme and flash yellow. See the
[artist guide](../sprinter-artist-assets.md) for geometry and import rules.
